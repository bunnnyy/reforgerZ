# Designs

Approved designs that aren't built yet ([CLAUDE.md](../CLAUDE.md), "Designs"). Each file says
"designed, not built" and never describes built behaviour; when it's built, its content moves into the
`docs/` file that owns the topic and the design file goes.

## Order of work

| Order | Design | What it is |
|---|---|---|
| 1 | [DUTIES.md](DUTIES.md) | The twenty duties the author approved, five a faction (the Haven's garden and swap table, Bastion's gate duty and kit inspection, the Red Hand's toll and still, Halcyon's decon line and observation ward...), most of them worked out and led by the player, and the Trusted rung's versions that wait. Built in phases; each phase's part moves into the docs. Built so far: work from the first day, the four rungs, the sorting duties played in the world, patrols and hunts with a place's people, things that happen, a watch, stock-taking and the Trusted rung ([docs/ERRANDS.md](../docs/ERRANDS.md#duties)) |

A new approved design goes here with its place in the order.
