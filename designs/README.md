# Designs

Approved designs that aren't built yet ([CLAUDE.md](../CLAUDE.md), "Designs"). Each file says
"designed, not built" and never describes built behaviour; when it's built, its content moves into the
`docs/` file that owns the topic and the design file goes.

Built so far: work from the first day and rungs 1 to 3, with the sorting duties played in the world and patrols and hunts with a place's people ([docs/ERRANDS.md](../docs/ERRANDS.md#duties)) |
