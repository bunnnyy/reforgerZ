# Designs

Approved designs that aren't built yet ([CLAUDE.md](../CLAUDE.md), "Designs"). Each file says
"designed, not built" and never describes built behaviour; when it's built, its content moves into the
`docs/` file that owns the topic and the design file goes.

## Order of work

| # | Design | What it is |
|---|---|---|
| 1 | [OPENINGS.md](OPENINGS.md) | Openings' phases 2 to 4 (phase 1 is built: [DESIGN.md](../docs/DESIGN.md#openings-how-every-life-starts)): each background's own step 2, the other two reasons and contacts, the earlier-life contact, the experience levels, the scenes as compositions, and lines for every background and reason |
| 2 | [SITES.md](SITES.md) | Camps that read as real places: each site's ground read on a grid with its surroundings (roads, water, high ground, hostile and friendly bases, the infected), placement rules and a solver in place of fixed plans, building in layers by each faction's doctrine (close off, harden, watch, then life), the people's posts, shifts, patrols and movement, each site's story, and an audit that scores every site |
